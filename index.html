Khắc phục lỗi lập trình

Top 5 Lỗi Phổ Biến Khi Lập Trình Python

1. SyntaxError: invalid syntax

Hay gặp nhất do quên dấu hai chấm (:) ở cuối câu lệnh if, for, while, def.

2. IndentationError: unexpected indent

Lỗi thụt lề không đồng đều. Luôn dùng 4 dấu cách (Space) hoặc 1 phím Tab cho khối lệnh con.

3. TypeError: can only concatenate str to str

Cố gắng cộng một chuỗi với số. Khắc phục bằng cách ép kiểu: str(so) hoặc int(input()).

4. NameError: name '...' is not defined

Gõ sai chính tả tên biến hoặc gọi biến trước khi khởi tạo. Nhớ rằng Python phân biệt chữ HOA và chữ thường!

5. IndexError: list index out of range

Truy cập chỉ số ngoài phạm vi. Hãy nhớ danh sách có N phần tử thì chỉ số đi từ 0 đến N - 1.
